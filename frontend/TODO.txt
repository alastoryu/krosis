🔍 Opção A (mais usada): câmera para leitura de código de barras

Você usa a câmera do celular via web:

Bibliotecas:
QuaggaJS (leve e simples)
ZXing (zxing-js) (mais robusto)
html5-qrcode (muito popular hoje)

👉 Fluxo:

Abre tela “Entrada de produtos”
Clica “Escanear”
Abre câmera
Lê código de barras
Sistema busca produto
Usuário só informa:
lote
validade
quantidade
